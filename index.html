📊 FUNCIONES DE BÚSQUEDA AVANZADA
BUSCARV + COINCIDIR
Aprende a buscar valores usando dos criterios simultáneos: por fila y por columna. La combinación perfecta para tablas extensas de ventas, datos cruzados o cualquier matriz de información.
=BUSCARV(ciudad; tabla; COINCIDIR(mes; encabezados; 0); FALSO)
🔍 Búsqueda por fila 📌 Posición dinámica ⚡ Columna flexible
01 — EL PROBLEMA
¿Por qué BUSCARV solo no es suficiente?
BUSCARV busca filas perfectamente… pero la columna es fija.
✅
LO QUE HACE BUSCARV
Busca por fila
Encuentra el valor en la primera columna y devuelve el dato de esa misma fila, pero de una columna fija que tú indicas con un número.
=BUSCARV("Lima"; A:Q; 5; FALSO)
⚠️
EL PROBLEMA
Columna fija = limitación
Si quieres buscar Enero usas columna 2, Febrero columna 3… tienes que cambiar el número manualmente cada vez.
=BUSCARV("Lima"; A:Q; ?; FALSO)
💡
La solución: usar COINCIDIR como indicador de columna
COINCIDIR calcula automáticamente en qué columna está el mes que buscas. Así el indicador de columna de BUSCARV se vuelve dinámico.

02 — FUNCIÓN COINCIDIR
Entendiendo COINCIDIR
Devuelve la posición de un elemento dentro de un rango. Simple pero poderosa.
SINTAXIS
=COINCIDIR(valor_buscado; matriz_buscada; tipo_de_coincidencia)
ARGUMENTO 1
valor_buscado
El mes que quieres encontrar. Referencia la celda donde el usuario escribirá el mes.

Ej: C4 → "Abril"
ARGUMENTO 2
matriz_buscada
La fila de encabezados donde están los meses. Incluye el título para que el número coincida con BUSCARV.

Ej: E2:Q2
ARGUMENTO 3
tipo_coincidencia
Escribe siempre 0 para coincidencia exacta. Así no hay errores por datos similares.

Siempre: 0
EJEMPLO
=COINCIDIR(C4; E2:Q2; 0)
📍
¿Qué devuelve exactamente?
Si buscas "Abril" y los meses van de Enero a Diciembre, pero incluiste el título (Ciudad) en la selección, COINCIDIR devuelve 5: el título cuenta como posición 1, luego Enero=2, Febrero=3, Marzo=4, Abril=5.
⚠️
¿Por qué incluir el encabezado de fila?
Porque en BUSCARV la primera columna es la de ciudades (posición 1). Si no incluyes el encabezado en COINCIDIR, los números no coincidirían y obtendrías datos incorrectos.
03 — COMBINACIÓN
BUSCARV con COINCIDIR anidado
COINCIDIR reemplaza el número fijo de columna en BUSCARV.
FÓRMULA COMPLETA
=BUSCARV(B4; E2:Q26; COINCIDIR(C4; E2:Q2; 0); FALSO)
01
valor_buscado → B4
La celda donde el usuario escribe (o selecciona) la ciudad. BUSCARV la buscará en la primera columna de la tabla.
B4 = "Lima"
02
matriz_tabla → E2:Q26
Toda la tabla de datos, incluyendo encabezados de fila y columna. La primera columna (E) debe ser la de ciudades.
E2:Q26 = tabla completa con headers
03
indicador_columnas → COINCIDIR(C4; E2:Q2; 0)
En vez de un número fijo, ponemos COINCIDIR que calcula dinámicamente la posición del mes que buscamos. Si el usuario elige "Abril" → devuelve 5.
COINCIDIR("Abril"; E2:Q2; 0) → 5
04
rango → FALSO
Siempre escribe FALSO para obtener una coincidencia exacta. Si la ciudad no existe en la tabla, mostrará #N/A en lugar de un dato incorrecto.
FALSO = coincidencia exacta obligatoria

05 — RESUMEN
Lo que aprendiste hoy
Tres conceptos clave para dominar la búsqueda bidimensional.
🔍
BUSCARV
Busca por fila
Localiza el valor en la primera columna y devuelve datos de esa misma fila.
📌
COINCIDIR
Posición dinámica
Calcula automáticamente el número de columna según el valor que buscamos.
⚡
JUNTAS
Búsqueda 2D
Una sola fórmula que localiza cualquier celda por fila Y columna sin tocar el número.
FÓRMULA MAESTRA — CÓPIALA
=BUSCARV(B4; E2:Q26; COINCIDIR(C4; E2:Q2; 0); FALSO)

Tip PRO: Añade listas desplegables

06 — CONTROL DE ERRORES
Función SI.ERROR
Captura errores y los reemplaza por mensajes útiles. Hoja limpia, sin sorpresas.
SINTAXIS
=SI.ERROR(valor; valor_si_error)
✅
SIN ERROR
Devuelve el resultado normal
Si la fórmula interna funciona correctamente, SI.ERROR simplemente muestra el resultado como si no estuviera. No interfiere en nada.
=SI.ERROR(BUSCARV(...); "—") → $14,200
🚨
CON ERROR
Muestra tu mensaje personalizado
Si la fórmula genera un error (#N/A, #DIV/0!, #REF!, etc.), SI.ERROR lo intercepta y muestra el texto o valor que tú definas.
=SI.ERROR(BUSCARV(...); "No encontrado")
⚠️
¿Qué errores captura?
Captura todos los tipos: #N/A (valor no encontrado), #DIV/0! (división entre cero), #REF! (referencia inválida), #VALOR!, #NUM! y más.
💬
Ejemplos de mensajes útiles
"El valor ingresado no es válido" "Ingrese los datos correctamente" "El valor debe ser diferente de cero"

Excel detectará automáticamente el rango de datos. También puedes seleccionar el rango manualmente antes de continuar.
02

En la cinta de opciones, pestaña Datos, grupo Herramientas de datos, haz clic en Quitar duplicados.

Tip PRO: Haz una copia antes
Esta operación es irreversible (salvo Ctrl+Z inmediato). Siempre guarda una copia de tus datos originales antes de eliminar duplicados.

📌
OPCIÓN 1
Delimitado
Divide el texto usando un carácter especial como separador: coma, punto y coma, espacio, tabulación o cualquier carácter personalizado.
"Ana,López,Lima" → 3 celdas
📏
OPCIÓN 2
Ancho fijo
Divide el texto en posiciones fijas. Útil cuando los datos tienen longitud fija, como códigos postales, IDs o datos de sistemas legacy.
"LIM001" → "LIM" + "001"
🛣️
Cómo acceder: Datos → Texto en columnas
Selecciona la columna con los datos → pestaña Datos → Texto en columnas. Se abrirá un asistente de 3 pasos que te guía paso a paso.
💡
Deja espacio para las columnas nuevas
Excel sobrescribirá las columnas a la derecha. Asegúrate de que estén vacías antes de aplicar, o inserta columnas nuevas primero.

Selecciona las filas o columnas a agrupar
Selecciona las filas de detalle (las que quieres ocultar). Por ejemplo, las filas 2, 3 y 4 del grupo Norte. No incluyas la fila de título ni el total.
02

En la pestaña Datos, grupo Esquema, haz clic en Agrupar. Aparecerán los controles [−] y [+] en el margen izquierdo o superior.
Atajo: Alt + Mayús + → (agrupar) / Alt + Mayús + ← (desagrupar)
03
Usa los botones de nivel 1 · 2 · 3
En la esquina superior izquierda aparecen botones de nivel. El nivel 1 muestra solo totales, el nivel 2 muestra los grupos, el nivel 3 muestra todo el detalle.
💡
Subtotal automático: úsalo junto con Agrupar
Datos → Subtotal crea automáticamente grupos y calcula sumas, promedios u otras funciones por categoría. ¡Dos herramientas que se complementan perfectamente!
