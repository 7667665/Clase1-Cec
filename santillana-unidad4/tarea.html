Práctica Unidad 4: Funciones de Excel

Excel · Unidad 4 · Funciones

Objetivo

Aplicar funciones de fecha, texto, matemáticas, estadísticas y lógica, además de combinar funciones, en un archivo de práctica con datos editoriales.

Indicaciones generales

  1. Descarga el archivo Excel de la Unidad 4 y ábrelo en Microsoft Excel.
  2. Utiliza la hoja Datos editoriales como fuente de información.
  3. Completa las hojas Fecha, Texto, Matematicas, Estadisticas, Logicas y Anidacion.
  4. Escribe las fórmulas en Excel. No sustituyas las fórmulas por resultados escritos manualmente.
  5. Completa la hoja Reto integrador y revisa los resultados.
  6. Guarda como Unidad4_Apellido_Nombre.xlsx y entrega el archivo en Moodle.

Actividades por bloque

Funciones de fecha

HOY, AHORA, DIAS360, FECHA. Utiliza datos del archivo y documenta un resultado comprobable.

Funciones de texto

LARGO, IZQUIERDA, DERECHA, EXTRAE (MED), CONCATENAR, ENCONTRAR, REPETIR. Utiliza datos del archivo y documenta un resultado comprobable.

Funciones matemáticas

SUMA, RESIDUO (RESTO), PRODUCTO, POTENCIA. Utiliza datos del archivo y documenta un resultado comprobable.

Funciones estadísticas

PROMEDIO, MAX, MIN, CONTAR. Utiliza datos del archivo y documenta un resultado comprobable.

Funciones lógicas

SI, SI.ERROR, Y, O. Utiliza datos del archivo y documenta un resultado comprobable.

Anidación de funciones

SI + Y, SI + SI.ERROR. Utiliza datos del archivo y documenta un resultado comprobable.

Reto integrador

Calcula el importe de cada libro, clasifica si cumple la meta de unidades, extrae el prefijo del código, obtiene estadísticas de ventas y combina SI con Y para validar resultados.
